# 🛒 Avbhimart E-Commerce Website

A modern and responsive E-Commerce website built using **HTML, CSS, and JavaScript**. This project provides a clean user interface with essential shopping features like product listing, search, cart management, and responsive design.

## 🚀 Features

- Responsive Design
- Product Listing
- Product Search & Filter
- Shopping Cart
- Add to Cart Functionality
- Remove Items from Cart
- Quantity Update
- Total Price Calculation
- Local Storage Support
- User-Friendly Interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
